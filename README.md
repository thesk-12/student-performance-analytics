# Student Performance Analytics System

A data analytics system built in Python using NumPy and Pandas to inspect, analyze, and report on student academic performance.

## Project Overview
This project processes student exam marks and attendance records to deliver:
- Automated calculation of total and average marks.
- Rule-based grade assignment (A+ through F) and subject-wise pass/fail verification.
- Statistical metrics including highest, lowest, median, standard deviation, and class averages.
- Subject-wise evaluations identifying strongest and weakest academic areas.
- Ranking and identification of top-performing students.

## Technology Stack
- **Language**: Python 3
- **Libraries**: Pandas, NumPy
